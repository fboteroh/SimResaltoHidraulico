# SimResaltoHidr-ulico
Simulador interactivo del resalto hidráulico en un canal rectangular con compuerta de fondo. Ajusta la profundidad del reservorio, la apertura, el ancho del canal y el nivel aguas abajo para ver al instante profundidades, velocidades, Froude, caudal, pérdida de energía, longitud y tipo de resalto, con flujo animado.
